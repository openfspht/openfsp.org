No provider implements OpenFSP natively yet. The [project phases](/docs#phases) set out what comes next.

| Component                                 | State                                                     | Link                                                                                                  |
| ----------------------------------------- | --------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Specification, protocol version `0.1.0`   | Available                                                 | [Specification](/docs/spec)                                                                           |
| Conformance JSON schemas                  | Available                                                 | [`conformance/schemas`](https://github.com/openfspht/openfsp/tree/main/conformance/schemas)           |
| OpenAPI description                       | Planned                                                   | [Payments API](/docs/spec/payments-api)                                                               |
| TypeScript SDK                            | Next step; client in the repository, not yet published    | [`frontend/packages/client`](https://github.com/openfspht/openfsp/tree/main/frontend/packages/client) |
| PHP and Python SDKs                       | Next step, after TypeScript                               | [Payments API](/docs/spec/payments-api)                                                               |
| Simulator, native provider `mock_openfsp` | Available                                                 | [Native provider](/docs/native-operator)                                                              |
| Conformance suite and CLI                 | Available, `gateway` and `native-operator` targets        | [Quickstart](/docs/quickstart#4)                                                                      |
| Transition gateway, MonCash and NatCash   | Available, tested against simulators; sandbox points open | [Gateway](/docs/gateway), [points to check](/docs/gateway#8.5)                                        |
| Admin console and demo shop               | Available                                                 | [Quickstart](/docs/quickstart#1)                                                                      |
| Signed attestations and browser verifier  | Available; the public validator is not online yet         | [Verify an attestation](/docs/verify)                                                                 |
| Refunds, capture, cancellation, proximity | Reserved capability names, not specified                  | [Capability registry](/docs/spec/capabilities#2)                                                      |
