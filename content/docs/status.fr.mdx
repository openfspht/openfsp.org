---
title: État du projet
description: L'état de chaque composant d'OpenFSP, disponible ou prévu.
---

Aucun opérateur n'implémente encore OpenFSP nativement. Les [phases du projet](/fr/docs#phases) indiquent la suite.

| Composant                                       | État                                                                        | Lien                                                                                                  |
| ----------------------------------------------- | --------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Spécification, version du protocole `0.1.0`     | Disponible                                                                  | [Spécification](/fr/docs/spec)                                                                        |
| Schémas JSON de conformité                      | Disponibles                                                                 | [`conformance/schemas`](https://github.com/openfspht/openfsp/tree/main/conformance/schemas)           |
| Description OpenAPI                             | Prévue                                                                      | [API des paiements](/fr/docs/spec/payments-api)                                                       |
| SDK Kotlin pour la JVM                          | Prochaine étape                                                             | [API des paiements](/fr/docs/spec/payments-api)                                                       |
| SDK TypeScript                                  | Prochaine étape, après Kotlin ; client disponible dans le dépôt, non publié | [`frontend/packages/client`](https://github.com/openfspht/openfsp/tree/main/frontend/packages/client) |
| SDK PHP et Python                               | Plus tard                                                                   | [API des paiements](/fr/docs/spec/payments-api)                                                       |
| Serveur simulé, opérateur natif `mock_openfsp`  | Disponible                                                                  | [Opérateur natif](/fr/docs/native-operator)                                                           |
| Suite de conformité et CLI                      | Disponibles, cibles `gateway` et `native-operator`                          | [Démarrage rapide](/fr/docs/quickstart#4)                                                             |
| Passerelle de transition, MonCash et NatCash    | Disponible, testée contre les simulateurs ; points de bac à sable ouverts   | [Passerelle](/fr/docs/gateway), [points à vérifier](/fr/docs/gateway#8.5)                             |
| Console d'administration et boutique de démo    | Disponibles                                                                 | [Démarrage rapide](/fr/docs/quickstart#1)                                                             |
| Attestations signées et vérificateur navigateur | Disponibles ; le validateur public n'est pas encore en ligne                | [Vérifier une attestation](/fr/docs/verify)                                                           |
| Remboursement, capture, annulation, proximité   | Noms de capacité réservés, non spécifiés                                    | [Registre des capacités](/fr/docs/spec/capabilities#2)                                                |
